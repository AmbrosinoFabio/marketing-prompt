# Security policy

Marketing Prompt is a static site (GitHub Pages) with no server, accounts or tracking.
Saved prompts stay in the visitor's browser (localStorage).

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
**Security → Report a vulnerability** on this repository.

In scope:
- the site (HTML, JavaScript, service worker) at https://ambrosinofabio.github.io/marketing-prompt/
- the GitHub Actions workflows and the scripts in `tools/`

Out of scope: the content of third-party news feeds and of the external sites linked
from the site.

This is a non-profit personal project: reports are answered on a best-effort basis.
