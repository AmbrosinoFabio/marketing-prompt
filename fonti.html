How the news is updated

Every day an automatic job on GitHub (GitHub Actions) reads the public feeds below and updates the list on the home page. For each item it keeps only the title, the source, the date, a link and a short excerpt (max ~300 characters): to read the article you go to the original site.

AI & promptingOpenAI news; Google AI and Gemini blogs; Google for Developers blog; updates of the Claude cookbooks, Anthropic courses and OpenAI cookbook repositories on GitHub
MarketingHubSpot Marketing blog, Moz blog, Ahrefs blog, Social Media Examiner
Watched pagesAnthropic has no RSS feed: the job checks the Claude prompting guide and the docs index for changes and opens a reminder (GitHub issue) to review the library.

Privacy

The site has no server-side part, no cookies and no analytics. What you write in "My prompts" is saved only in your browser's local storage (localStorage) on your device; nobody else can read it. The backup file you export is saved where you choose. The "Open in Claude" button opens claude.ai in a new tab with the prompt text in the address (link): only if you click it, that text reaches Anthropic, under Anthropic's privacy policy. The site is hosted on GitHub Pages, which may keep technical logs (such as IP addresses) under GitHub's privacy statement.

Use of artificial intelligence

Prompts, translations and page texts were drafted with the help of an AI assistant (Claude, by Anthropic) and published under the editorial responsibility of the author, who reviews them. They may still contain errors: check every AI output before using it in your work. Found a mistake? Report it on GitHub.

Privacy

Il sito non ha una parte lato server, non usa cookie né statistiche. Quello che scrivi in "I miei prompt" viene salvato solo nell'archivio locale del tuo browser (localStorage), sul tuo dispositivo: nessun altro può leggerlo. Il file di backup che esporti viene salvato dove scegli tu. Il pulsante "Apri in Claude" apre claude.ai in una nuova scheda con il testo del prompt nell'indirizzo (link): solo se lo clicchi, quel testo arriva ad Anthropic, secondo l'informativa privacy di Anthropic. Il sito è ospitato su GitHub Pages, che può conservare dati tecnici (come gli indirizzi IP) secondo l'informativa privacy di GitHub.
